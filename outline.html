三個大哉問：資料 → 走到 → 認出

資料要訓練就要 bug → 只好自己生成 → 太規律、不像真的，模型看不到真實 bug
走到AI 沒找到 bug → 分不出是沒走到、沒認出，還是本來就沒有
認出正確答案因遊戲、場景、風格而異，有時不在畫面上 → 很難泛化
▼

可能的解決方式（題目縮小，每關推一步）

資料：貼近真實照真實 bug 分布決定注入什麼
單一遊戲微調，用真實 bug 測
走到：拆開來量讀遊戲內部狀態確認有沒有觸發
回報 → 結構化步驟 → 專用介面重現
認出：不只看畫面加輸入、遊戲狀態、正確數值
時間性改輸入設計
參考畫面與門檻壓誤報
